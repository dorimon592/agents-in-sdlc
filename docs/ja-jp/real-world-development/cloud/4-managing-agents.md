前の 2 つの演習では、Copilot cloud agent にユーザー体験の改善と機能の追加に関する 3 つのタスクを依頼しました。cloud agent は非同期かつ自律的に動作しますが、タスクを監視することも重要です。

cloud agent に割り当てたタスクを管理する方法はいくつかあります。[GitHub のエージェントページ][agents-page]では、オープンなプルリクエスト (PR) があるすべてのエージェントタスクを確認できます。実行内容を調べたり、進行中のセッションに指示を与えたりできます。

このレッスンでは、次のことを行います。

- エージェントページで cloud agent のタスクを監視します。
- 進行中のセッションに指示を追加し、機能をリクエストします。

## シナリオ

エージェントにハイコントラストモードの作成を依頼した後、チームはライトモードも追加したいと考えました。サイトのスタイルを更新し、切り替え機能を追加しているところなので、ライトモードも含めるのが合理的です。ハイコントラストだけでなくライトモードも実装するよう、エージェントに指示します。

## Copilot cloud agent のタスクを確認する

Copilot cloud agent に割り当てたタスクの現在の状態を確認しましょう。

1. [Copilot エージェントページ](https://github.com/copilot/agents)に移動します。
2. メインペインと左ペインの両方に表示されるタスクの一覧を確認します。Copilot に割り当てた次のようなタスクがあります。
    - コードベースのドキュメントの更新
    - ゲームを変更する API の生成
    - Web サイトへのハイコントラストモードの追加
3. 実行中のタスクを選択します。Copilot が行った次のような処理を確認します。
    - リポジトリからコードをチェックアウトする
    - Copilot が作業する環境を作成する
    - MCP サーバーをセットアップする
    - 割り当てられたタスクを完了するためにさまざまな処理を実行する

> [!NOTE]
> 表示される手順は、Copilot の作業状況や採用した方法によって異なります。

4. 右側に表示されるプルリクエスト (PR) ペインも確認してください。ここから PR と変更ファイルを確認し、作業を監視できます。

## cloud agent に指示を追加する

次に、ハイコントラストモードの作業中にライトモードも追加するよう Copilot に依頼します。

1. ハイコントラストモードの追加に関するセッションを選択します。Copilot が付けた名前や作業状況によって、タイトルは異なります。

    ![ミッションコントロールに表示されたアクセシビリティのセッション](../../../_images/ex6-accessibility-session.png)

2. セットアップが完了し、作業が始まるまで、数分間セッションを確認します。作業が始まると、次のようなメッセージが表示されます。
3. **Steer active session while Copilot is working** ダイアログに次のプロンプトを入力します。

    ```plaintext
    ハイコントラストモードの作業に加えて、ライトモードも追加してください。ユーザーが希望する表示モードを選べるよう、ライトモードの切り替えも追加してください。
    ```

    ![エージェントページで進行中の cloud agent のタスクを表示し、Steer active session while Copilot is working ダイアログを示すスクリーンショット](../../../_images/ex6-steer-cloud-agent-task.png)

4. <kbd>Enter</kbd> を押して、プロンプトを送信します。
5. Copilot がプロンプトを確認し、作業に取り込むことを確認します。

## Copilot に作業を任せる

前と同じように、Copilot は更新されたタスクに取り組みます。メッセージを送信した時点で実行中の処理を終えてから、新しい依頼を作業に反映します。

この作業にも数分かかります。その間に休憩して、ここまでに学んだことを振り返りましょう。

## まとめと次のステップ

Copilot cloud agent のタスクを監視し、案内するための中心的な場所であるエージェントページについて学びました。ミッションコントロールでは、進行中と完了済みのタスクを追跡し、実行中の作業を確認して、作業範囲の変更や追加の指示を出すことができます。

このレッスンでは、次のことを確認しました。

- ミッションコントロールとエージェントページで cloud agent のタスクを監視する方法
- 進行中のセッションに指示を追加して機能を依頼する方法

Copilot がアクセシビリティ機能を実装している間に、Copilot が作成した[プルリクエストを反復する][next-lesson]方法を確認しましょう。
